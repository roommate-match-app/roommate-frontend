# КакДостать Соседа — Frontend

Клиентская часть приложения для поиска соседа, написанная на React + TypeScript с использованием сборщика Vite.

## Локальный запуск (через npm)
Убедитесь, что у вас установлен Node.js версии 18 или выше.
1. Установите зависимости: `npm install`
2. Запустите сервер для разработки: `npm run dev`
3. Приложение будет доступно в браузере по адресу: `http://localhost:5173`
